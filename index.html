Comment ça marche

Le principe

Le bot tourne en permanence sur votre serveur (Katabump) et répond automatiquement aux messages privés reçus sur votre compte Telegram. Cette application est la télécommande : elle change les réglages du bot à distance.

Accueil
  • Activer / désactiver les réponses automatiques.
  • Statistiques : personnes, messages reçus, réponses envoyées.
  • Délai : chaque personne reçoit une réponse toutes les X heures (5 par défaut), pas à chaque message.
Message, image, emojis premium
  • Message texte : la réponse par défaut.
  • Image en autocollant : une image de votre galerie, envoyée comme autocollant avant le message.
  • Emojis premium : bouton « Emojis premium » sous le message, touchez un emoji pour l’ajouter.
  • Import Telegram : préparez votre réponse dans « Messages enregistrés » (emojis premium, autocollants, photos), puis importez-la. Le bot renvoie une copie fidèle.
  • Si un import existe, il remplace le texte et l’image. Utilisez « Supprimer l’import » pour revenir au texte.
  • Les emojis premium ne s’affichent que si votre compte a Telegram Premium.
Mots-clés

Si le message reçu contient un mot-clé, le bot envoie la réponse associée (texte seulement) au lieu du message par défaut.

Planning

Choisissez les heures pendant lesquelles le bot répond. L’heure utilisée est celle de la Tunisie (UTC+1), modifiable dans app.py (TIMEZONE_OFFSET_HOURS).

Accès aux photos
  • L’application est un site emballé en APK : l’accès à la galerie dépend de l’outil qui a créé l’APK.
  • Sur le site de conversion, activez l’option de téléversement de fichiers / accès au stockage / galerie si elle existe, puis reconstruisez l’APK.
  • Sur le téléphone : Paramètres → Applications → l’application → Autorisations → Photos et médias (ou Fichiers) → Autoriser.
  • Sinon : envoyez l’autocollant dans « Messages enregistrés » sur Telegram, puis utilisez « Importer depuis Telegram ».
Journal, listes, planning par jour, variables
  • Journal : les 60 derniers messages reçus (📩) et réponses envoyées (📤). Le bouton 🚫 ajoute la personne à la liste.
  • Liste noire : le bot ignore ces personnes. Liste blanche : il répond uniquement à elles. Ajout par @username (la personne doit avoir déjà écrit) ou par ID.
  • Planning par jour (onglet Planning) : une ligne par jour avec ses heures ; décochez un jour pour le désactiver.
  • Message d’absence : envoyé une fois par délai quand le planning est fermé. Vide = silence.
  • Variables dans le message, les mots-clés et l’absence : {nom} prénom, {username} @pseudo, {heure} 14:30, {date} 14/11/2026.
Nouveautés : modèles, emojis standard, courbe
  • Modèles (onglet Message) : écrivez un message, donnez un nom, « Enregistrer… ». Pour le réutiliser : choisissez-le puis « Utiliser » (il est envoyé au serveur tout de suite).
  • Emojis standard : sous « Emojis premium », touchez un emoji pour l’ajouter. Ils s’affichent chez tout le monde.
  • Conversion : cochez la case pour que chaque emoji premium devienne son emoji standard équivalent à l’enregistrement (aucun risque de ne pas s’afficher).
  • Courbe (Accueil) : activité des messages reçus.
Réglages : PIN, alertes, sauvegarde
  • PIN : saisissez 4 à 8 chiffres puis « Activer ». L’application se verrouille à chaque ouverture. C’est un verrou d’interface : il protège contre un regard rapide, pas contre un expert.
  • Alertes : cochez la case ; si la connexion tombe, le téléphone vibre et un message s’affiche.
  • Sauvegarde : « Sauvegarder » génère un texte JSON (message, délai, planning, mots-clés, modèles) à garder. « Restaurer » : collez-le dans la zone puis appuyez ; les mots-clés déjà présents sont ignorés.
  • Installation : l’application peut s’installer (PWA) et affiche sa dernière interface sans internet.
Sécurité
  • Ne partagez jamais votre jeton, votre API_HASH ni le fichier .session.
  • Le fichier .session donne un accès complet à votre compte.
  • Pour changer le jeton, modifiez API_TOKEN dans app.py et redémarrez le serveur.
Dépannage
  • « Impossible de joindre le serveur » : vérifiez que le serveur est en ligne et que le port est le bon.
  • « Jeton incorrect » : le jeton doit être identique à API_TOKEN dans app.py.
  • L’import échoue : le bot doit être connecté à Telegram et « Messages enregistrés » doit contenir votre message.
